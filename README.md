# DevOps Flask Project

A beginner-friendly DevOps project that demonstrates a complete CI/CD workflow for a Python Flask application.

## Tech Stack

- Python
- Flask
- Pytest
- Git & GitHub
- GitHub Actions
- Docker
- Docker Hub

## Project Workflow

```text
Flask Application
       ↓
      Git
       ↓
    GitHub
       ↓
GitHub Actions
       ↓
   Run Tests
       ↓
 Docker Build
       ↓
 Docker Hub
       ↓
 Docker Container
       ↓
    localhost
